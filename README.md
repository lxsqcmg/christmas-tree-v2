# christmas-tree-v17.6 🎄

一棵可以拖动旋转、能被动作点亮、还会炸开的粒子圣诞树。单文件 HTML，无依赖、可离线运行。

线上地址：https://ll2643571625-cpu.github.io/christmas-tree-v17.6/

---

## 可视化设置面板（右下角「🎄 设置」）

打开网页点左下角「**🎄 设置**」，所有改动即时生效，并自动记住（下次打开还是这套）。

| 分组 | 可调内容 |
|---|---|
| 氛围配色 | 经典金 / 冰蓝 / 玫红 / 极光绿 / 紫夜（背景 + 文字 + 星光） |
| 树身颜色 | 松绿 / 深林 / 冰青 / 雪白 / 香槟 |
| 灯光颜色 | 多彩 / 暖金 / 冰白 / 粉紫 / 青绿 |
| 树的形状 | 经典锥形 / 细长优雅 / 枝繁叶茂 / 极简光带 |
| 粒子密度 | 0.5×～2.0×（越密越实，越稀越通透） |
| 装饰元素 | 彩灯灯串 / 飘雪 / 金色光尘 / 顶部星星 / 炸开光环，各自开关 |
| 文字 | 第一行大字、第二行小字、献给谁（留空则隐藏该行） |
| 植入照片 | 树中挂饰 / 做背景 / 不要，可随时换图 |

**复制分享链接**：把当前这套设置编码进 `#s=...`，别人打开就是你调好的那一版。
照片只走本地存储、不上传服务器，分享链接里也不含照片（对方会看到没有照片的版本）。

## 交互

- **点一下屏幕**：整棵树炸开成漫天星尘，约 2.6 秒后粒子归位长回圣诞树。
- **左右拖动**：手动转动圣诞树。
- **开启摄像头互动**：挥手/走动会让灯串变亮变快；动作够大也会触发炸开。
  摄像头画面会被压成暗冷蓝色做背景，只在本地处理，不上传（需要 https）。

## 文字 / 参数微调（不想用面板时）

也可以直接在 `index.html` 的 `DEFAULTS` 里改默认值，或用链接参数：

- `?name=小美`：临时覆盖祝福对象。
- `#s=<编码>`：从「复制分享链接」得到的完整设置。

炸开手感相关变量：`BURST_OUT`（炸开用时）、`BURST_TOTAL`（从炸开到长回总时长）、
粒子里的 `bs` 随机范围（飞散距离）。

## 怎么在线编辑

1. 打开仓库 → 点 `index.html` → 右上角 ✏️
2. 改完拉到底部点 **Commit changes**
3. 约 1 分钟 Pages 自动重建，刷新线上链接即生效

在仓库页按键盘 **`.`** 可打开 VS Code 网页版（github.dev），改起来更顺手。

## 技术

纯 Canvas 2D：锥形粒子树身 + 螺旋彩灯（独立闪烁相位）+ 飘雪 + 光尘 + 透视投影与深度排序；
摄像头经 `getUserMedia` 取样做帧差判断动作强度；炸开是「缓出散开 + 平滑回收」的位移曲线。
无第三方库、无外部资源，全部逻辑在一个 HTML 文件里。
